# RAG d'exemple

Ce dossier contient des documents de contexte pour enrichir les prompts de l'agent.

## Exemples de contenus

- l’œuvre est une peinture romantique avec un fort contraste visuel ;
- l'audiodescription doit rester accessible et descriptive ;
- le fond sonore doit renforcer l'ambiance sans masquer les éléments visuels ;
- les descriptions doivent être sensibles à l'art et aux émotions.
